# Deck

A terminal-pane notification card for Ryoku.

- The app name sits in a dark-blue pill, like a starship path pill.
- The summary reads like a command after a `λ` prompt; the body lines up under it.
- A thin rail on the left edge marks the card and turns to the error colour for
  urgent notifications.
- Actions are small outlined tabs, like tmux pane titles.
- A hairline drains along the foot while a timed popup waits; persistent popups
  draw none, and reduced motion turns it off.

Every colour is a Material role from the live palette (`primaryContainer`,
`primary`, `error`, `surfaceContainerLow`), so the card follows the wallpaper.
Text uses JetBrainsMono Nerd Font.

Pick it in **Settings -> Overlays** after installing it from **RyoStore ->
Notifications**.
